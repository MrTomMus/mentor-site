# Frontend Mentor Portfolio

Персональный сайт-портфолио Frontend-ментора.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Форма заявки

После валидации и согласия форма открывает Telegram-чат с [@sergey55578](https://t.me/sergey55578) и готовым текстом заявки. Пользователь нажимает «Отправить» в Telegram.

В сообщение также добавляются сведения о согласии (версия, дата, язык, страница).

Bot token и серверный API для заявок не используются.

## Placeholders в юридических документах

Значения задаются в `src/config/site.ts` (`operatorName`, `operatorLocation`, `privacyEmail`, `siteDomain`, `privacyEffectiveDate`) и подставляются в тексты политики и согласия.

## Персональные данные: действия владельца сайта

Владельцу сайта нужно самостоятельно:

- поддерживать актуальные контакты и домен в `src/config/site.ts`;
- проверить необходимость подачи уведомления в Роскомнадзор;
- проверить требования к локализации баз данных граждан РФ;
- проверить договоры и условия используемых хостинговых и облачных сервисов;
- определить фактические сроки хранения;
- регулярно удалять устаревшие заявки в Telegram;
- обеспечить доступ к Telegram-аккаунту с двухфакторной аутентификацией;
- ограничить круг лиц, имеющих доступ к заявкам;
- подготовить порядок действий при утечке данных;
- актуализировать политику при изменении формы, аналитики или сервисов.

### Обработка запроса на удаление / изменение данных

1. Проверить личность заявителя разумным способом.
2. Найти данные в Telegram, email и других местах хранения.
3. Удалить их, если нет законных оснований продолжать хранение.
4. Подтвердить выполнение запроса заявителю.
5. Не пересылать запросы и персональные данные посторонним лицам.

### Предупреждение о локализации

Если через форму собираются персональные данные граждан РФ, владельцу сайта необходимо отдельно проверить требования законодательства РФ к первичной записи и хранению таких данных, а также инфраструктуру хостинга, логов и интеграции с Telegram.

## Сторонние сервисы и cookies

- **Timeweb Cloud** — хостинг frontend
- **Telegram** — получение заявок через личные сообщения (ссылка t.me)
- **Google Fonts** — шрифты
- **localStorage** — тема и язык

Не найдено: Google Analytics, Яндекс Метрика, Meta Pixel, рекламные пиксели. Cookie-баннер не используется.
